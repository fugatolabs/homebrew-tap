# Fugato Homebrew tap

Homebrew formulae for [Fugato](https://github.com/fugatolabs/fugato), local
development environments for Git worktrees.

Install Fugato with:

```sh
brew install fugatolabs/tap/fugato
```

Release archives and checksums come from the Fugato GitHub releases. Formula
updates are reviewed after the release's four-platform installation checks pass.

Report vulnerabilities using the Fugato repository's private reporting form.
For project documentation and contribution guidance, see the main repository.

The tap is licensed under Apache-2.0. The installed Fugato package includes
its license and third-party notices.
